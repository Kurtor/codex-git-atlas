# Git Atlas 内嵌仓库浏览视觉验收

验收范围：1440 × 1024 Windows 桌面窗口，使用 Git Atlas 自身真实仓库；验证最近仓库、路径输入、目录浏览、当前仓库状态和主工作台并存。

## 设计判断

- 产品类型：开发者使用的高密度本地桌面工具。
- 目标：仓库切换不离开工作台，不遮挡提交上下文，也不依赖系统选择弹窗。
- 参数：设计变化 5 / 动效 3 / 信息密度 9。
- 视觉策略：沿用石墨底色、品牌蓝和 3px 圆角；浏览态把左栏从 250px 展开至 320px，不增加浮层、光晕或装饰动画。

## 迭代记录

### 第一轮：7.8 / 10

- 已完成左栏最近仓库、路径输入、文件列表和 Git 目录操作。
- 未通过项：Windows 路径分隔符不一致造成当前仓库重复；当前目录按钮未正确识别已打开状态；250px 下路径识别效率不足。

### 第二轮：9.2 / 10

- 路径统一规范化，最近仓库去重，当前仓库识别正确。
- 浏览态左栏扩展至 320px，主图与详情保持可见，没有遮罩和弹窗。
- 目录列表按 Git 仓库、普通文件夹、文件排序；单次上限 180 项，排除 `.git` 与 `node_modules`。
- 最近仓库持久化上限 8 个，首屏显示 3 个，避免挤压本机文件列表。

## 自动验收

- 类型检查：通过。
- Web 构建：通过，JavaScript gzip 约 91.1 KB，CSS gzip 约 13.5 KB。
- Electron 真实仓库检查：22 / 22 通过。
- 渲染器错误：0。
- 关键检查：内嵌仓库浏览、真实 Git 历史、搜索、稳定拓扑、分支可达性、四模式差异、风险解释、Merge / Rebase 标记均通过。

最终自评：9.2 / 10。扣分主要来自左栏宽度有限，无法同时永久展示完整分支列表和文件列表；当前采用原位双态切换，在信息密度与操作连续性之间更稳妥。
