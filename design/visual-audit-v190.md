# Git Atlas v1.9 视觉与产品自审

## 产品判断

v1.9 从既有 Git 图谱工作台继续演进：完整保留提交演化、因果场、模块影响、风险路径和 Git 操作，再增加平级的 AI 协作解释层。最终定位是：**以 Git 为事实底座、以 Codex 为意图上下文的本地代码演化工作台**。

Git 提供提交、分支、作者、时间、Merge、Rebase 和变更规模；Codex 提供用户目标、可见行动、文件事件和验证状态。任何跨来源关系如果没有精确 SHA，只能标为“自动关联”。

## 两轮自审

### 第一轮：8.6 / 10

- 任务脉络、代码地图、人机交接与验证债务已经有独立信息结构。
- 未通过：Codex 存档中的响应注释和浏览器上下文污染任务目标。
- 未通过：验证命令识别过宽，把包含 `test` 路径的普通读取误认为验证。
- 未通过：验证债务较少时中央区域信息密度不足。

### 第二轮：9.2 / 10

- 只保留 `## My request` 后的真实用户目标，并过滤环境包装。
- 验证规则收紧到明确的测试、构建、类型检查与 lint 命令。
- 验证债务增加阻断数、验证总数、通过数和逐条验证账本。
- 四模式在 1440 × 1024 桌面窗口逐一截图检查；Git 证据回退视图同步验收。

### Git 权重复审：9.4 / 10

- 将核心证据单元改为“Git × Codex”，而不是单向 AI 任务流。
- 任务脉络的第三节点直接展示真实 Git 提交与 Codex 文件事件。
- 右侧改为“任务 × Git 变更档案”，关联提交成为一级指标。
- 顶部使用“AI 协作 / Git 图谱”平级切换；进入 Git 图谱后，既有四模式恢复完整的大标题导航和工作区。
- README 的首屏截图来自真实桌面程序，不使用概念稿或演示假数据。

## 信息与审美检查

- 信息密度：左侧任务和回合、中间证据链、右侧档案、底部 Git 时间线均有明确职责，没有为装饰留大面积空卡片。
- 视觉层级：蓝色表示任务脉络，青色表示代码触达，紫色表示交接，橙色表示验证债务；Git 实证固定为绿色来源标签，不随模式变化。
- 证据边界：Git 实证、Codex 事件、自动关联和 AI 推断使用不同标签；当前实现不展示 AI 推断结论。
- 隐私：主进程丢弃 reasoning、原始 Diff 和完整命令输出；渲染层无法访问这些字段。
- 资源：AI 证据默认关闭且不轮询；读取完成立即退出 App Server，避免约 105 MB 的无效常驻工作集。
- 可操作性：AI 证据和 Codex 仓库跟随分别拥有显式开关；Git 操作仍使用白名单、结构化参数和破坏性操作限制。
